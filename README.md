# FuturePrint AI Studio

Free local artwork and PDF tools for Windows and Linux.

[Website](https://futureprintai.com) · [Downloads and installation help](https://futureprintai.com/downloads)

This repository distributes tested installers and release notes. The desktop application is proprietary freeware; its included license permits free personal and commercial use. Open-source dependencies retain their own licenses. Installing the desktop tools does not require a FuturePrint account.

## Downloads

Use the **Releases** section for available installers, checksums and exact tested operating systems. Download only a published release; the source-code ZIP generated by GitHub is not an installer.

- **Linux:** Ubuntu/Debian x64 `.deb` package.
- **Windows:** x64 installation bundle, including the setup program, corresponding document-runtime source and license terms. Extract the complete bundle before installing.
- **macOS:** no qualified release is available.

These are unsigned early-access releases. Windows can identify the installer as an unknown publisher. Checksums identify the downloaded file; they are not a publisher signature.

## What works locally

Image import and editing, resizing, layered project save/reopen and image export; PDF text overlays, imported-image signatures, saved document drafts, PDF export and page-image conversion. An image signature is a visual mark, not a certificate-backed digital signature.

Physical printing and calibrated color/ink output remain experimental. AI generation, account services and payments are not included in the currently available public service. Optional OCR and Office conversion require separately installed local tools. Consult each release's notes for its actual qualification scope.

## Support

Report reproducible software bugs through this repository's Issues. Include the application version, operating system, steps and error text. Do not publish passwords, API keys, private documents or personal information. Contact details are also available at [futureprintai.com/contact](https://futureprintai.com/contact).

Builds and qualification run locally. This repository does not use GitHub Actions.
